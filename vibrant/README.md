# Magazine New Tab - Chrome Extension (Manifest V3)

A digital magazine new tab for macOS Chrome with realistic open-spread spine curvature and stacked page depth.

## Installation on macOS Chrome:

1. Open Google Chrome.
2. Navigate to `chrome://extensions/` in your address bar.
3. In the top-right corner of the Extensions page, enable **Developer mode** (开发者模式).
4. In the top-left corner, click **Load unpacked** (加载已解压的扩展程序).
5. Select this `extension` folder.
6. Open a new tab (Cmd + T) — your magazine new tab is now active!
