# 📖 Magazine New Tab - Chrome 扩展（Manifest V3）
**将你的新标签页变成一本杂志。**。
如果你喜欢的网站变成了杂志里的插画，会怎么样？
Magazine New Tab 把你的新标签页变成一本杂志，将收藏的网址变成杂志的排版内容。
## 🎨 01 — Vibrant
1.色彩丰富、具有活力与视觉表现力  
2.你可以选择点击顶部圆点切换颜色

## 🚀 在 macOS 的 Chrome 上安装
1. 下载或克隆本仓库。
2. 在 Google Chrome 中打开 `chrome://extensions/`。
3. 启用 **开发者模式**。
4. 点击 **加载已解压的扩展程序**。
5. 选择 `vibrant/` 或 `editorial/` 文件夹。
打开一个新标签页，尽情享受吧！🥰
