# 📖 Magazine New Tab

**把你的新标签页变成一本杂志。**

如果你最喜欢的网站，能变成一本数字杂志里的插画，会怎么样？

Magazine New Tab 将浏览器的新标签页变成一个充满视觉趣味的空间，让你收藏的网站变成杂志般的体验。

## 🚀 开始体验

1. 下载或克隆本仓库。
2. 在 Google Chrome 中打开 `chrome://extensions/`。
3. 开启 **开发者模式**。
4. 点击 **加载已解压的扩展程序**。
5. 选择 `vibrant/` 或 `editorial/` 文件夹。

打开一个新标签页，开始体验吧！🥰
